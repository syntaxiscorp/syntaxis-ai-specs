
## Proceso de Login Salfa

## Contexto
Este documento tiene el fin de definir el paso a paso de la integración con el servicio de salfa.  esto se hace mediante la conexión  a distintos endpoint de la empresa Salfa , la cual es llamado un middleware de inicio de sesión, el cual le entrega un token con el Scope necesario para hacer uso de la api a utilizar. 


## Flujo
Se debe hacer el llamado a una serie de endpoint para la obtención del token   . el url base es dependiendo el environment.
- QA: https://apiautorizadorqa.salfagestion.cl/api/v1.0
- PROD: https://autorizadorapi.salfagestion.cl/api/v1.0
# 1 - Iniciar Login

| Endpoint           | Tipo | Modelo            | Retorna |
| ------------------ | ---- | ----------------- | ------- |
| token/iniciarLogin | POST | IniciarLoginModel | String  |

```js
export class IniciarLoginModel { 
public clientId: string; //id de la aplicacion (debe ser entregada por salfa) 
public returnUrl: string;  //url a donde sera retornada una vez generado el login 
constructor() { this.clientId = null; this.returnUrl = null; }
```
# 2 - Obtener Token

| Endpoint           | Tipo | Modelo            | Retorna    |
| ------------------ | ---- | ----------------- | ---------- |
| token/obtenerToken | POST | ObtenerTokenModel | TokenModel |
|                    |      |                   |            |
```js
export class ObtenerTokenModel { 
public code: string; //son los parametros que genera el proceso 1 
pubic clientId: string; //id de la aplicacion (debe ser entregada por salfa) 
public returnUrl: string; //url a donde sera retornada la aplicacion una vez generado el login, debe ser el mismo que se usa en IniciarLoginModel
	constructor() { 
	this.code = null;
	this.clientId = null;
	this.returnUrl = null; 
	} 
}
```
# 3 - Obtener Usuario
| Endpoint             | Tipo | Modelo | Retorna      |
| -------------------- | ---- | ------ | ------------ |
| token/obtenerUsuario | GET  |        | UsuarioModel |
 ```js
 export class UsuarioModel { 
public contactoId: string; //es el contactoId de la persona conectada 
public given_name: string; //es el usuario de la persona conectada 
public sub: string; //el id del usuario en autorizador
public preferred_username: string; //es el nombre de la persona conectada 
public email: string; //es el email de la persona conectada 
public claims: [string]; //datos adicionales de la persona conectada 
	constructor() { 
	this.contactoId = null; 
	this.given_name = null;
	this.sub = null; 
	this.preferred_username = null;
	this.email = null;
	this.claims = null; 
	 } 
}
 ```
# 4 - Cerrar Sesión
| Endpoint           | Tipo | Modelo            | Retorna |
| ------------------ | ---- | ----------------- | ------- |
| token/cerrarSesion | POST | CerrarSesionModel | string  |
```js
export class CerrarSesionModel { 
public id_token: string; //es el id del token en sesion public 
logoutUrl: string; //url a donde retorna una vez cerrada la sesion
	 constructor() { 
	 this.id_token = null; 
	 this.logoutUrl = null; 
	 }
}
```
